# Obchody-tabulka v1.3.0 Evidence obchodů, import obchodů z Excelu, import provizních výpisů, kontrola provizí a roční plán. ## Verze v1.3.0 - odstraněna samostatná záložka Import provizí a Nastavení - import provizí přes Evidence obchodů - evidence podle měsíců podle data sjednání - upravené sloupce: klient, kategorie, společnost, produkt, datum, platba, BJ, očekávaný zisk, skutečná provize, rozdíl, stav, typař, typař vyplacen, poznámka - upravitelný stav obchodu - zaškrtávátko pro vyplacení typaře - koeficient BJ v Ročním plánu - automatický výpočet očekávaného zisku: BJ × koeficient - možnost smazat řádky importované ze screenu ## Nasazení Nahraj soubor `index.html` do složky `Obchody-tabulka`, nebo jej přejmenuj na `Obchody-tabulka.html` podle aktuálního GitHub Pages odkazu.
