# Obchody-tabulka Statická aplikace pro evidenci obchodů, import provizních výpisů, kontrolu skutečných provizí a sledování ročního plánu. ## Aktuální verze **v1.1.0** Při každé další úpravě změňte číslo verze v souboru `index.html` na dvou místech: 1. v hlavičce stránky u textu `v1.1.0` 2. v JavaScriptu u řádku `const VERSION='v1.1.0';` ## Funkce ve verzi v1.1.0 - evidence obchodů - ruční přidání obchodu - import/export JSON zálohy - export obchodů do CSV - import provizního výpisu XLSX - automatické párování provizí podle čísla smlouvy / klienta / produktu / společnosti - upozornění na nové nebo nespárované provize - upozornění na obchody starší než 3 měsíce bez provize - dashboard s měsíčním grafem výdělku - roční plán: klienti, BJ, investice, čistý zisk - plnění plánu v procentech ## Důležité Data se ukládají lokálně v prohlížeči. Pro jistotu pravidelně používejte **Export JSON**. ## Novinky v1.1.0 - Evidence obchodů rozdělená po měsících podle data sjednání. - Import aktuální tabulky obchodů z Excelu/XLSX. - Import provizí ukazuje, co se propsalo a co zůstalo nespárované. - Základní OCR import ze screenu přes Tesseract.js s nutnou ruční kontrolou.
